# Run actions

This function produces the animation that shows all actions performed by
Karel since its world was generated by `generate_world`.

## Uso

``` r
run_actions(loop = FALSE)
```

## Argumentos

- loop:

  A logical value TRUE or FALSE indicating if the animation should
  repeat itself after finished or not (defaults to FALSE).

## Valor

Produces an animation with `gganimate`.

## Ver también

[`generate_world`](https://docs.ropensci.org/karel/reference/generate_world.md)

## Ejemplos

``` r
generate_world("mundo001")

move()
pick_beeper()
turn_left()
put_beeper()
if (interactive()) run_actions()
```
